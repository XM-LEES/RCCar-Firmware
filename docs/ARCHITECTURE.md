# 架构

固件以 `feature/ackermann-chassis` 为基线整理。保留下行命令、RC 接管、停止覆盖、转向标定和板载电压采集；移除 IMU 等未安装设备的占位链路，适配电调模式二，并以 ESC 转速作为主速度反馈。上行另传独立 Hall 周期测速结果。电脑端收帧与原始数据回放已验证，C63A A3 物理链路实测异常；ESC RX 已迁到 PD15 软件 UART，等待实板验证，转速物理比例仍待实测。

## 速度闭环

![速度环与模式二动作](diagrams/speed-loop.svg)

车速幅值为 `|v| = eRPM × C / (60 × p × G档 × G轮)`。`p` 为极对数，`C` 为车轮周长，各减速比均取输入转速 / 输出转速。方向依据最终生效的电调动作历史估计，不能由负向 PWM 或遥测原始状态直接推断。方向未知时仍可观测正的速度幅值，但方向可信位清零且角速度不生成；控制器不能把该正值解释为前进。传动模型不消除打滑和轮胎形变误差。

自动推进沿用基线的**前馈脉宽＋PI 微调**：

- 目标速度经原有缩放、限幅、低速死区和变化率约束，得到 `v参考`。
- 基准脉宽 `p前馈 = F方向(v参考)`，取自原前进／倒车标定表。
- `e = v参考 − v反馈`，`Δp = clip(Kp·e + Ki·∫e dt, −Δp上限, +Δp上限)`，单位为 µs。
- 推进请求为 `p前馈 + Δp`，受对应动作的输出边界约束；微调不能跨入另一动作区。

PI 保留抗积分饱和和换向清积分约束；使用新鲜 ESC 样本更新反馈，重复读取同一样本不增加积分时间。原表和原增益在模式二下的效果标注为未验证，不能将 µs 制增益直接当作归一化出力增益。

前进超速使用独立比例刹车 `b = clip(Kb·(|v反馈| − |v参考|), 0, b上限)`。切入与释放带滞回，制动请求先撤销原有推进；刹车脉宽和力度单独标定，不套用旧倒车限幅。

## 模式二约束

| 场景 | 动作关系 |
| --- | --- |
| 前进减速或停车 | 第一次负向输入用于刹车，同次制动连续保持 |
| 前进转倒车 | 连续制动达到首击确认力度与时长 → 新停稳证据 → 回中驻留 → 第二次负向输入 |
| 已知前进状态、无第一击记录的倒车请求 | 停稳 → 第一击 → 回中 → 重新确认停稳 → 驻留 → 再次负向输入 |
| 启动或控制历史失效后的倒车请求 | 保持中点；须先由明确的前进请求产生实际正向输出，重新建立电调状态 |
| 倒车减速或转前进 | 收油滑行；转前进必须取得新停稳证据，不假定具备对称主动刹车 |

实际正向推进重置倒车触发历史。刹车释放回中后，再次刹车须先建立正向推进状态。普通弱刹不等于已满足倒车许可；首击力度不足或中途被覆盖时，不能以重新回中、重新计时来自动重试负向输入。夹入零速命令不能绕过换向停稳约束。以上模式二动作与本车脉宽、时序的对应关系未验证。

软件复位或清除历史不代表电调已经复位。首次启动、RC 接管、反馈失效和换向超时之后，电调的倒车许可状态按未知处理；新停稳证据只能证明低速，不能证明下一次负向输入必定是刹车。第一版因此禁止未知状态下自动发出负向首击，也不会为了恢复状态自行向前驱动。人工 RC 路径保留原仲裁规则。

停稳要求多个不同的新鲜低速样本覆盖设定时长。新的推进、制动或首击动作使此前证据失效；连续保持同一制动动作时，可积累动作开始之后的低速样本，重复读取同一样本不能累计证据。停稳窗口不等于机械锁止或驻车制动。

## 运行边界

输出仲裁沿用基线：RC 停止优先，普通 RC 接管优先于串口源；无生效控制源时输出中点。串口 SOFTWARE_STOP 是该命令源的停止覆盖，不是故障锁存；CLEAR_FAULT 的受理条件与诊断语义见[接口约束](INTERFACES.md)。

ESC 反馈无效或关键传动参数缺失时禁止自动闭环推进，不回退到 Hall 测速；恢复自动推进前重新取得停稳证据。明确换向请求设有超时边界，零目标自然滑停保持中点。转向与 RC 路径保留基线的输入有效性、限幅和停止处理。
